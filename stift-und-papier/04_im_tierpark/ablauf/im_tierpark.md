# Ablauf `Im Tierpark`

> **Ziele**: Bestehenden Code lesen und verstehen; Array-Methoden anwenden; Objekte besser verstehen

> **Themen**: Arrays, Loops, Objekte

1. Drucke im Vorhinein das Beiblatt [im_tierpark_arbeitsblatt.pdf](../material/im_tierpark_arbeitsblatt.pdf) halb so viel mal aus wie Personen vor Ort im Unterricht sind. 
2. Die Klasse soll sich in 2er-Gruppen aufteilen und pro Gruppe soll [index.html](../index.html) im LiveServer geöffnet werden und die Konsole aktiviert werden. Dort wird ein Array mit einem Tierpark zu sehen sein. Es soll ausserdem die Datei [szenarien.md](../szenarien.md) geöffnet werden.
3. Es soll nun für jeden der beschriebenen Szenarien das entsprechende Code-Snippet auf dem Arbeitsblatt gefunden werden. 3 Snippets passen zu keinem der beschriebenen Szenarien. Dort soll kurz beschrieben werden, was im Code passiert, bzw. was das Szenario wäre.
4. Sobald alle Gruppen fertig sind (max. 30') wird die Übung anhand der [Lösungen](../solution/script.js) im Plenum besprochen.
