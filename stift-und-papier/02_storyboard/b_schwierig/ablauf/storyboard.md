# Ablauf `Storyboard`

> **Ziele**: HTML & CSS analysieren; DOM und Event-Listener verstehen;

> **Themen**: DOM; Event-Listener; Zusammenhänge HTML, CSS & JavaScript

1. Drucke im Vorhinein das Beiblatt [storyboard_arbeitsblatt.pdf](../material/storyboard_arbeitsblatt.pdf) halb so viel mal aus wie Personen vor Ort im Unterricht sind. 
2. Die Klasse soll sich in 2er-Gruppen aufteilen. 
3. Die Dozierenden/LBA's erklären die Übung und besprechen mit den Studierenden die Ausgangslage (also kurz über HTML und CSS schauen), sodass alle wissen, wo sie beginnen sollen. Es soll auc kurz die Ausgangslage im Code gezeigt werden (also alles auskommentieren in script.js und index.html mit dem Live Server öffnen).
4. Die Studierenden sollen dann selbständig Schritt für Schritt in [script.js](../script.js) die Schritte abarbeiten und jeweils skizzieren, wie sich die Webseite nach dem jeweiligen Schritt verändert. Die auf dem Arbeitsblatt beschriebenen User-Interaktionen sollen in die Skizze einfliessen. 
5. Sobald alle Gruppen fertig sind (max. 45') wird die Übung im Plenum besprochen.
